# Reconcile uncertain effect attempts instead of replaying operations

An accepted Operation may survive a crash even when OnePage cannot know whether its external effect occurred. OnePage therefore records each execution try as a distinct Attempt with a durable disposition in the Session Ledger and chooses recovery by effect class: a model or Bash dispatch that may have begun is not automatically repeated as the same Attempt, while a one-file patch observes the preimage, expected postimage, divergence, or invalid target bound by its durable Patch Intent. Expected postimage completes without reapplication; divergence or invalid state stops without writing. An indeterminate Bash Result enters Conversation as a Tool Result so the Agent can inspect external state and choose its next action; uncertainty alone neither forces User intervention nor terminates the Job. This rejects generic automatic retry and any exactly-once claim for effects outside OnePage's transaction boundary.
