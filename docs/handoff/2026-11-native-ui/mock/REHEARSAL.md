Concept preview only, not shipped UI or evidence from a product test. No real commands or upgrades run.

## Source and approach
Gold: Stageshow `examples/ai-chat` (copied and filmed before adaptation; `shots/gold.png`, `shots/gold-film.log`). Kept its Stage/Window/Act structure, once-through script and reduced-motion poster; replaced the chat with one quiet terminal. The upgrade scene is idle and types `/upgrade`, then uses the bottom line for checking, upgrading and completion. An outside-terminal selector presents checking, upgrading, already current, success, blocked and failure as named concept states, with retry guidance on the latter two; replay restores the scripted happy path. Queue and quiet-tools views are separate selectable scenarios. The compact composition uses shorter prose and a bottom crop to keep the window framing and status in view. This is an isolated preview and does not modify the source skill or Rui production.
