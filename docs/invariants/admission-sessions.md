## Seams the harness must provide

- Inject a clock and deterministic ID collision source at Store creation (`src/store/domain/configuration.zig`, `src/store/Store.zig`).
- Gate commit/reply, queue selection, provider delivery and Action completion and inject commit failures (`src/store/domain/command.zig`, `src/server.zig`); all gates must be explicit handshakes.
- Supply in-process fake provider and executor and isolate each Store and transport (`src/server.zig`). Product recovery needs a process crash cut and a fake clock/provider.
- Inject file publication failures and expose captured bytes to a fake transport for client capture (`src/client.zig`); avoid filesystem scheduling assumptions.
