The SL-1 owner covers real agent births, a three-level subtree beyond the first page, controlled work-change times and archive filter cases. Its MySQL execution remains a required hosted check. The SL-2 owner checks returned facts and SQLite VM work before and after adding 128 unrelated Sessions; it does not establish a bound for arbitrary subtree size. The subtree walk is unbounded and streamed by design: one statement reads every eligible descendant with its work, and each row is folded into its root's totals as it arrives, so memory stays constant while the read Access holds the Store queue for O(descendants) keyed probes.
