## Seams the harness must provide

- `src/server_execution.zig:670` and `src/execution_turn.zig:46`: inject separate service and Store clocks, retry entropy, and count discovery; the functional turn context already accepts scripted observations.
- `src/server_execution.zig:1648` and `src/store/domain/model_settlement.zig:631`: expose barriers after Attempt commit, before launch/send, after seal, before/after settlement and during cleanup; process crash tests need barriers visible across process death.
- `src/server_execution.zig:194`, `src/bash.zig:105` and `src/server_mcp.zig`: inject fake provider, spawn, process-group, pipe and MCP send/response adapters with explicit completion and send certainty; no network or sleeps.
- `src/server_execution.zig:1111`, `src/named_scratch.zig:64` and `src/output_retention.zig:34`: inject canonical read/write and file I/O/cleanup faults, including short and unknown partial writes. Retention already accepts a removal adapter.
- `src/ScratchBudget.zig:14` and Host allocation/descriptor owners: expose accounting and bounded live-resource counters; count owned allocations and handles separately, not RSS.
- `src/BashLifecycle.zig:81` already accepts explicit observations and time; keep its public state-machine seam and connect it to the in-process Host harness.
- `src/tool_result.zig:44`, `src/core_tools.zig` and provider codecs: expose deterministic value-level rendering and provider request capture, including compound parts; preserve existing immutable output readers.
