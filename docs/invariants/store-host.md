## Seams the harness must provide

Inject a clock and barriers for commit, launch, shutdown and lease retirement in `src/server.zig`, `src/host_start.zig`, `src/store/Store.zig` and `src/host_restart.zig`; expose effect and storage faults through public harness adapters. Supply fake provider and local release download fixtures in `src/provider.zig` and `src/release_candidate.zig`, a private Host discovery namespace, terminal handoff observation, and a temporary HOME/runtime per test. Inject deterministic MySQL protocol, epoch and commit-loss outcomes in the MySQL connection owner; preserve the pinned previous-release workflow and its historical binary compatibility evidence.
