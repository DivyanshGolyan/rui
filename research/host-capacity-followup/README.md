# Throwaway control and memory follow-up

This extends the [capacity experiment](../host-capacity-scaling/README.md). The first matrix in `results.json` compares a stop check after a whole owner pass (mode 1) with a check between individual result settlements (mode 2). Nineteen cases passed: three repetitions of both modes at 100/500/1,000 and a separate five-wave memory probe at 1,000.

A separate synthetic sender thread requests stop after result settlement begins. The owner commits a row in a scratch `probe_stop` table; the reactor removes the exact held-open model transfer; the server observes EOF; the owner records cancellation and releases the target's scratch/custody. This is an owner-scheduling and cancellation experiment, not production Run API ingress, Session-stop traversal, or a crash/replay guarantee. The held target never normally completes, so it does not test completion/cancellation races. Compare request, commit, removal and release timestamps separately.

The memory probe sums all malloc zones with `malloc_zone_statistics(NULL, ...)`. After five waves, live malloc allocations were 1.49 MiB while physical footprint was 55.44 MiB. After transport/database/library closure and two seconds of natural idle, live allocations were 1.34 MiB and footprint 54.19 MiB. A diagnostic relief call left live allocations unchanged while footprint fell to 6.35 MiB. Allocator reservation is not resident RAM, and live allocations do not distinguish reachable objects from leaks. Five waves do not establish indefinite stability.

Reproduce with `python3 research/host-capacity-followup/experiment.py`. It reuses the previous experiment's temporary custom-curl build recipe. Recorded execution built the dependency first and used `run.py --curl-build /tmp/onepage-capacity-followup-curl/curl-8.7.1`. The convenience wrapper composes those commands and is not separately rerun. The earlier system-libcurl descriptor limitation and experimental poll override still apply. No production code, accepted resource policy, or system library is changed.
