# macOS libcurl build qualification: source evidence

Researched 2026-09-06. Read-only research; no dependency selection or production qualification. Local reproduction results below were supplied by the parent task, not rerun here.

## Findings that affect the decision

1. **The old high-descriptor limitation exists inside libcurl as well as its outer wait API.** Upstream 8.7.1 TCP connection progress calls `SOCKET_WRITABLE(ctx->sock, 0)`; the macro invokes `Curl_socket_check`, which invokes `Curl_poll`. Without `HAVE_POLL_FINE`, that helper falls back to select and rejects descriptors outside `FD_SETSIZE`. An application using socket_action can therefore still encounter this internal limit. This is source-confirmed for upstream 8.7.1; it does not establish the precise source/patches of Apple's binary. [Connection path](https://github.com/curl/curl/blob/curl-8_7_1/lib/cf-socket.c#L1181-L1204), [macro and guard](https://github.com/curl/curl/blob/curl-8_7_1/lib/select.h#L76-L111), [poll/select helper](https://github.com/curl/curl/blob/curl-8_7_1/lib/select.c).

   Parent's new isolated proof agrees with this explanation: one plain HTTP transfer at an explicitly duplicated socket descriptor succeeds at 1023; socket_action returns transfer error 7 at 1024 and 1100 with zero bytes. No TLS or concurrent load is needed. This confirms the binary's boundary, while attribution to this exact internal call remains an inference without tracing Apple's binary. Raising RLIMIT_NOFILE does not change a library's compiled select representation.

2. **Upstream fixed the Darwin poll policy in curl 8.11.0, released November 6, 2024.** Commit `c72cefea0fadaf4114a0036c86005ee5739ec30a` uses poll whenever present, avoiding poll only for zero-socket sleeps. Its rationale explicitly identifies Apple's old zero-socket poll bug and internal select's descriptor-1024 problem. It removes HAVE_POLL_FINE special handling. Current 8.22.0 configure detects HAVE_POLL normally; a current upstream candidate should not require the prototype's 8.7.1 config override. This is a source finding, not proof that a current build passes OnePage's workload. [Fix and rationale](https://github.com/curl/curl/commit/c72cefea0fadaf4114a0036c86005ee5739ec30a), [release changelog](https://curl.se/changes.html#8_11_0), [8.22.0 configure](https://github.com/curl/curl/blob/curl-8_22_0/configure.ac#L4220-L4235).

   Historical context: 8.7.1 disabled poll across Darwin because it had been broken before 10.9 and again in 10.12. The original report concerns premature return when polling zero descriptors. Do not present that historical bug as evidence that current macOS poll is unusable. [8.7.1 policy](https://github.com/curl/curl/blob/curl-8_7_1/m4/curl-functions.m4#L4021-L4031), [original report](https://github.com/curl/curl/issues/1057).

3. **A modern upstream upgrade changes the TLS dependency choice.** The latest standard release listed today is 8.22.0, September 2, 2026. Upstream removed Secure Transport in 8.15.0. Therefore the experimental 8.7.1 + Secure Transport build cannot simply be version-bumped while retaining that backend. [Release list](https://curl.se/docs/versions.html), [Secure Transport removal](https://curl.se/changes.html#8_15_0).

4. **Native Apple trust and native Apple TLS are different choices.** Modern curl supports Apple SecTrust certificate verification with OpenSSL-compatible TLS or GnuTLS. Configure's `--with-apple-sectrust` was added in 8.17.0. This retains Apple trust evaluation while using another TLS engine; it is not a restored Secure Transport backend. The custom-CA behavior matters for the fixture: specifying a CA file normally replaces SecTrust verification; combining native CA and a custom CA explicitly enables both. [Build option](https://curl.se/docs/install.html), [Apple trust behavior](https://curl.se/docs/sslcerts.html#apple--opensslgnutls).

## Smallest useful next qualification

The source evidence supports testing an unmodified current upstream curl candidate with an explicitly identified supported TLS backend and trust configuration. It does not choose that candidate for the product. Record exact version/configuration, linked dependency hashes, minimum supported macOS, native/custom trust behavior, and repeat the isolated high-descriptor proof before full TLS/resource/cancellation measurements. Avoid carrying the experimental HAVE_POLL_FINE override forward without first checking the standard build.

The current system binary fails a basic descriptor-number case; reducing simultaneous operations is not a principled fix, because unrelated Host files can make a single socket receive a high descriptor. A bundled dependency transfers update/build responsibility to OnePage; the research has not yet compared that maintenance cost with other transport implementations. No memory/default/SLO numbers follow from these source facts.
